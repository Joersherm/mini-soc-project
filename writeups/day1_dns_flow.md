# Day 1: DNS and IP Adresses

## Objective
Understand how IP Addresses are tracked and how the computer looks up IPs

## Concepts
- DNS translates domain names to IP addresses.
- Communication is done with IP address and not domain name.
- There are many routers involved in sending traffic to a server on the internet.
- Latency impacts communication speed.

## Lab

### ping google.com
Returns google.com's IP along with the time it takes for packets to travel there and back and checks for connectivity

### nslookup google.com
Returns what IP belongs to google.com and which DNS server was used to find this information

### traceroute google.com
Shows route packets take across networks
