# Mini SOC Project

A hands-on cybersecurity lab focused on:
- attack simulation
- packet analysis
- detection engineering
- incident response
- SOC workflows

## Tools
- Ubuntu
- Wireshark
- Python
- VirtualBox
- Kali Linux (later)

## Structure
- architecture/ → network diagrams
- logs/ → captured logs
- attacks/ → simulated attacks
- detections/ → alert logic and scripts
- screenshots/ → evidence
- writeups/ → incident reports
